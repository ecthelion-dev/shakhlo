# Shahlo Boutique — Link-in-Bio (Taplink muqobili)

Ushbu veb-sahifa **Shahlo Boutique** brendi uchun maxsus tayyorlangan, zamonaviy, nafis (boutique) uslubidagi bepul va cheklovlarsiz havolalar sahifasi (Link-in-Bio).

## 🌟 Afzalliklari
- **100% Bepul** — Hech qanday oylik to'lov yoki obuna talab etilmaydi.
- **Tezkor yuklanish** — Mobil qurilmalarda chaqmoqdek tez ochiladi.
- **Jonli do'kon holati** — Vaqtga qarab "Hozir ochiq" yoki "Hozir yopiq" ko'rsatiladi.
- **Netlify-ready** — Netlify platformasiga bir zumda yuklash mumkin.

## 📁 Fayllar tuzilishi
- `index.html` — Sahifaning asosiy tuzilishi va dizayni.
- `style.css` — Maxsus nafis animatsiyalar va ranglar.
- `script.js` — Telegram, telefon, ijtimoiy tarmoqlar havolalari va do'kon ish vaqti hisoblagichi.
- `netlify.toml` — Netlify serveri uchun xavfsizlik va optimallashtirish sozlamalari.

## ✏️ Ma'lumotlarni qanday o'zgartirish mumkin?
`script.js` faylining eng boshidagi `BOUTIQUE_CONFIG` obyektidan telefon raqam, telegram kanal, lokatsiya va ish vaqtini osongina o'zgartirishingiz mumkin.

## 🚀 Netlifyga joylash (Deploy qilish)
1. [netlify.com](https://www.netlify.com) saytiga kiring.
2. Tizimga kiring (Sign up / Log in).
3. "Sites" bo'limida **"Add new site" -> "Deploy manually"** tugmasini bosing.
4. Ushbu papkani shunchaki sichqoncha bilan brauzerga tortib tashlang (Drag & Drop).
5. 10 soniyada sizga `shahlo-boutique.netlify.app` kabi bepul rasmiy havola beriladi!
